02 — Flagship Project

LyTrix — Programming Language System

LyTrix
Programming Language System
GitHub Repository ↗

LyTrix is a programming language system developed to understand language architecture, parsing, execution flow, and compiler concepts. It encompasses two independent implementations built in Java, each exploring a distinct internal architecture and execution model.

LyTrix-R · Interpreter
Completed

Interpreter implementation built from scratch to handle expression evaluation, AST traversal, and execution flow.

  • Custom Lexer / Tokenization
  • Parser & Abstract Syntax Tree (AST)
  • Node Visitor / Interpreter Architecture
  • Expression Evaluation & Type Handling
  • EOM-Based Return Concept
  • BackLine() Main-Function Replacement
Java Interpreter AST Visitor
LyTrix-Q · Compiler
In Progress

A separate compiler-oriented implementation with a different internal architecture targeting intermediate code generation.

  • Compiler Pipeline Architecture
  • Intermediate Representation (IR)
  • QBE Backend Integration
  • SSA-Oriented Transformation Concepts
  • Planned Native Compilation Target
