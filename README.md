# Daniel Raj V — Developer Portfolio Architecture

A high-performance, cyber-luxury developer portfolio digital archive built for **Daniel Raj V** (B.Tech Information Technology, LICET Chennai).

## 🚀 Architecture Overview

- **3-Tier Depth Palette**: Pure pitch-black void (`#000000`), panel base (`#050505`), and elevated surface (`#0A0A0C`).
- **Signature Tone**: Kinetic Luxury Orange (`#FF4500` / `#FF5F1F` / `#FF6B35`) accenting focal actions and telemetry.
- **Micro-Interactions**:
  - **Pseudo-3D WebGL Particle Matrix**: 90-node ambient starfield with Z-depth projection and connection data pulses.
  - **Grid Proximity Sensor**: 72px grid lines brightening near cursor coordinates.
  - **Backdrop Canvas Spotlight**: Smooth radial gradient tracking cursor movements.
  - **Dual-Element Custom Cursor Engine**: Elastic spring ring lerp shape-shifting over interactive targets.
  - **Laser SVG Border-Draw**: Dynamic perimeter calculation stroke animation.

## 🛠️ Interactive Instruments

1. **LyTrix Language System Pipeline**:
   - Live editable source code.
   - Live SVG/D3 AST tree graph generator.
   - QBE SSA IR side-by-side diff view.
   - Profiler telemetry log stream.
2. **Binary Adder Hardware Sandbox**:
   - 2-Bit and 4-Bit Ripple Carry Adder mode toggles.
   - Real-time digital logic gate equations (XOR, AND, OR) and animated wire schematics.
3. **Architecture Pipelines**:
   - Parkin Today ANPR Jetson Nano sequential flow.
   - Luna Carin local AI assistant (whisper + Groq/Llama + Piper TTS).
   - E-Seva REST API & MySQL ER schema.
   - ROAM.ver self-hosted pocket server tunnel architecture.
4. **Command Palette**:
   - Triggered via `⌘K` / `Ctrl+K` for fuzzy navigation across sections, instruments, and logs.

## ⌨️ Accessibility & Shortcuts

- `⌘K` / `Ctrl+K`: Open/Close Command Palette.
- `ESC` / `ENTER`: Skip terminal boot intro sequence.
- Keyboard readable focus states and WCAG AA contrast against pure black.
